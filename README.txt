اختبار الوحدة الأولى: العمل والأمل — الصف الثالث الابتدائي
Cloudflare Pages + Pages Functions + D1

هذه الحزمة مبنية على ملف HTML المحدّث الذي أرسله المستخدم في 17 أكتوبر 2026.
تم الإبقاء على بنك الأسئلة وتصميم الاختبار وشهادة التقدير ولوحة المعلم، وتحويل حفظ النتائج والإعدادات إلى Cloudflare D1.
تم حذف تكامل Firebase المضمن في النسخة الأصلية؛ المشروع يستخدم Cloudflare Pages Functions فقط.

محتويات الحزمة:
- index.html: الاختبار بعد ربطه بواجهات Cloudflare، مع بيانات معاينة مناسبة لمشاركة الرابط.
- functions/: وظائف حفظ النتائج وحساب الدرجة على الخادم ولوحة المعلم والإعدادات ومسح السجل.
- schema.sql: إنشاء جداول D1.
- _routes.json: مسارات الوظائف.
- كل محاولة تُحفظ في السحابة، ويُحسب التقييم على الخادم باستخدام مفتاح الإجابة المستخرج من هذا الملف الأصلي.

الخطوات:
1) فك ضغط ZIP.
2) أنشئ GitHub repository جديدًا وخاصًا، مثل: quiz-grade3-work-hope-v2.
3) ارفع كل محتويات الحزمة إلى جذر المستودع. يجب أن يظهر index.html ومجلد functions مباشرة في الصفحة الرئيسية للمستودع.
4) من Cloudflare افتح Workers & Pages -> Create application. إذا ظهرت واجهة Workers الجديدة، اختر Continue to Pages. ثم Connect to Git واختر المستودع الجديد.
5) إعدادات البناء: Production branch = main، Build command = exit 0، Build output directory = . ثم Save and Deploy.
6) أنشئ قاعدة D1 مستقلة باسم: arabic-grade3-work-hope-db.
7) افتح قاعدة D1 -> Console، والصق كامل محتوى schema.sql، ثم Execute. يمكنك التحقق عبر:
   SELECT name, type FROM sqlite_master WHERE type IN ('table', 'index') ORDER BY type, name;
   ينبغي أن يظهر results وsettings.
8) في مشروع Pages افتح Settings -> Bindings -> Add -> D1 database. اجعل Variable name = DB واختر arabic-grade3-work-hope-db ثم احفظ.
9) في Settings -> Variables and Secrets أضف Secret باسم TEACHER_PASSWORD وقيمته كلمة مرور خاصة بك. لا تضع كلمة المرور في HTML أو GitHub.
10) أعد نشر آخر نسخة Production بعد إضافة الـBinding والـSecret.
11) افتح رابط الإنتاج الأساسي الذي ينتهي بـ .pages.dev (ليس Preview).
12) أرسل محاولة اختبار تجريبية، وتأكد من ظهور رسالة نجاح الحفظ السحابي على شاشة النتيجة.
13) افتح لوحة المعلم وأدخل كلمة المرور، ثم تأكد من ظهور المحاولة.
14) أعد الاختبار من موبايل وتحقق من ظهور نتيجته في لوحة المعلم على الكمبيوتر.

ملاحظات:
- استخدم قاعدة مستقلة لهذا المشروع حتى لا تختلط النتائج مع مشاريعك الأخرى.
- خيارات الإجابة تُخلط ترتيبها للطالب؛ النسخة تحتفظ بمؤشر كل اختيار الأصلي لكي يصحح الخادم باستخدام مفتاح الإجابة الأصلي.
- لم يتم حفظ النتائج في localStorage؛ المصدر الرسمي للنتائج هو D1.
- تغيير كلمة المرور يتم من Secret TEACHER_PASSWORD ثم إعادة النشر.
- مسح السجل من لوحة المعلم يمسح نتائج هذه القاعدة السحابية بعد تأكيدك.
- مشاركة الرابط: استخدم رابط الإنتاج الأساسي، وليس رابط Preview ذي المعرّف المسبق.
